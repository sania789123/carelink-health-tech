# CareLink Health Tech
Connected Care, Beyond the Consultation

## Setup
Terminal 1 (backend):
    cd backend
    npm install
    cp .env.example .env
    npm run seed
    npm run dev

Terminal 2 (frontend):
    cd frontend
    npm install
    npm run dev

Open http://localhost:5173
